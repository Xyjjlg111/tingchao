# dsh-tingchao —— 设置里的「听潮」判断标准面板

一个 DSH 客户端插件：在 **设置 → 听潮** 里用卡片管理「谁该用哪套判断标准」。

## 它解决什么

耳朵（`.`）判一句语音，用的是「按这个人的说话习惯归一化 → 质心 → 门槛」。
门槛原来只有一个全局值，于是：

- 哥哥那种「宿舍里压着嗓子、累也不说」的说话方式，会被通用门槛判成「低落」；
- 群里几十个人共用一个门槛，谁都不准。

这个面板把门槛拆成三层：**个人专属 → 群专属 → 通用**。

## 三层怎么生效

```
一句语音进来
  → 有个人专属标准且启用？  用它
  → 没有？在这个群里、有群标准且启用？ 用它
  → 都没有？用通用标准
```

计算本身不变（还是那 3 个特征 + 质心 + 距离闸），变的只是「多确定才敢说」：

- `总门槛 (minMargin)`：越高越谨慎。
- `生气 / 低落` 各自的门槛：调高 = 更不容易给这个情绪下结论。
- `关键词`：大肥鱼对这个人的印象，写给人看的（面板里醒目显示），不参与算分——它是给「生成初稿」和人工判断用的参考。

## 面板结构

设置 → 听潮，三个页签：

1. **通用标准** —— 所有没有专属标准的人用它。
2. **个人（N）** —— 每个 QQ 一张卡片：身份标签（哥哥/主人/只写 QQ 号）、昵称、关键词 chips、门槛滑条、启用开关、保存/删除；底部「加一个人」可按最近语音生成初稿。
3. **群聊** —— 桥接里有记录的群；每张卡片显示成员、谁有「个人」标准、谁「随群」，并可直接给这个群写一套群标准；底部「加一个群」可先建标准等它出现。

## 数据

- 标准：`.\data\standards.json`（人 + 群 + 通用，纯文本，可手改）
- 基线条数：来自 `.\data\baselines.json`
- 初稿来源：`.\data\observations.jsonl`（只有数字，没有音频、没有原文）

## 宿主半边

`index.js` 只做转发，把面板请求转给本机 `127.0.0.1:3098`：

| 面板请求 | 耳朵服务 |
|---|---|
| `GET /tingchao-7340/standards` | `GET /standards` |
| `POST /tingchao-7340/standards` | `POST /standards` |
| `POST /tingchao-7340/standards/delete` | `POST /standards/delete` |
| `GET /tingchao-7340/derive?qq=` | `GET /standards/derive?speaker=` |
| `GET /tingchao-7340/overview` | 读桥接 `social-v2.json` + `/standards` |
| `GET /tingchao-7340/health` | `GET /health` |

耳朵挂了时面板显示「读不到」而不是崩掉。

## 安装形态（与 dsh-fish-heart 相同）

- profile 的 `dsh.profile.bundles` 里加 `dsh-tingchao`
- `node_modules\dsh-tingchao` 是指向本目录的 junction（pnpm 的 `link:` 也认，但离线时用 junction 最稳）
- 改 `client.js` 只需刷新页面；改 `index.js` 需要重启 DSH

## 已知边界

- 群标准只按「群号」生效；群号来自桥接的会话 key（`group:<群号>`）。
- 初稿只统计这个人在已有语音里的中位数，样本 <5 条时拒绝生成。
- 面板不显示/不保存音频，也不改基线本身。

## 门槛怎么定（tune-standards.mjs）

不用手猜，也不要拿没有标签的自己的语音去"驯"（那等于自己给自己打分）。做法：

```
node .\tune-standards.mjs --target 0.7            # 只看，不写
node .\tune-standards.mjs --angry 0.45 --sad 0.24 --apply
```

它用**线上模型**在 CASIA 的 1,000 条上算每个片段最近/次近距离比，再扫门槛，
输出「说了多少条 / 说对多少条」，并拿你的真实观测（只读数字）对比新旧门槛下会说几条。

2026-11-08 的结论（哥哥这张卡）：CASIA 上 angry 的"说出口准确率"最高只有 60%，
sad 在 0.24 时约 72% —— 所以 angry 门槛压到 0.45（几乎只在极清楚时说）、
sad 落到 0.24（宁可多说一点，但都带"像"字）。他 63 条观测：旧门槛说 14 条 / 提示 23 条，
新门槛说 8 条 / 提示 29 条。
