# 设置 → 听潮（控制面板）

## 三层判定

```
这个人有「个人专属」且启用？ → 用个人的
没有 → 这个群有「群标准」且启用？ → 用群的
都没有 → 通用标准
```

## 三个页签

1. **通用标准**：所有没有专属的人用它。
2. **个人**：一个 QQ 一张卡 —— 身份标签（"哥哥（主人）"/ 只写 QQ 号）、昵称、关键词、门槛滑条、开关。
3. **群聊**：每个群一张卡，显示成员、谁有个人标准、谁随群；可直接给群写标准。

## 每个 QQ 的专属标准怎么形成

两种方式，可以混用：

1. **自动初稿**：「加一个人」→ 填 QQ + 身份 → 点「按最近语音生成初稿」。
   它读最近 7 天的观测（只要数字，不含音频），给出语速/停顿/音高特征和关键词建议。
2. **人工写关键词**：大肥鱼对这个人的印象（"宿舍里压着嗓子""累也不说"）——
   这是给人看的参考，也决定你在面板里一眼能不能认出这个人。

## 门槛怎么理解

- **总门槛**：越高越谨慎。
- **生气 / 低落**：各自一条。调高 = 更少下这个结论。
- 建议：生气调高（机器判生气最不准），低落略低（日常最容易出现）。

## 关键词从哪来

- `/standards/derive` 会把中位数翻成词：语速偏慢 / 停顿偏多 / 嗓音偏低 / 说话偏轻。
- 剩下的由你补。面板里每个词都是一个 chip，可以直接改。
